# Hayase extensions — anitorrent

Rust port of [anh9000/anitorrent](https://raw.githubusercontent.com/anh9000/anitorrent/main/hayase/index.json).

This folder is a complete GitHub repo. Upload `index.json` **and** the `.wasm` files so users can import without building.

## Import

After you push this folder:

`https://raw.githubusercontent.com/<you>/<repo>/main/index.json`

Or locally, paste the path to this `index.json` in Settings → Extensions.
